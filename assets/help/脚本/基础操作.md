# 脚本基础

j-cli 可以保存常用的命令脚本，起一个名字，以后一行命令就能执行。就像给常用操作设置快捷键。

## 什么是脚本？

脚本就是一段保存好的命令。比如你经常需要执行一条很长的部署命令，不用每次都手动输入，保存成脚本就行：

```bash
# 创建一个叫 deploy 的脚本
j script deploy "cd ~/my-project && git pull && cargo build --release"

# 以后只需要：
j deploy              # 自动执行那条长命令
```

## 怎么创建脚本？

两种方式：

```bash
# 方式一：命令行直接创建
j script deploy "git pull && make build"

# 方式二：打开编辑器写（适合复杂脚本）
j script deploy
```

打开编辑器后，可以写多行命令，保存退出即可。

## 执行脚本

```bash
j deploy              # 在当前终端执行
j deploy -w           # 在新终端窗口中执行
```

`-w` 参数会打开一个新的终端窗口来运行脚本，不影响当前终端。

## 倒计时功能

j-cli 还内置了一个倒计时工具：

```bash
j time countdown 30s       # 30 秒倒计时
j time countdown 5m        # 5 分钟倒计时
j time countdown 1h        # 1 小时倒计时
j time countdown 25        # 不带单位默认按分钟（25 分钟）
```

倒计时结束后会发出声音提醒。

## 环境变量

脚本执行时，你的所有别名都会自动变成环境变量（全大写、`J_` 前缀）：

```bash
# 如果你有一个别名叫 chrome
# 脚本里可以用 $J_CHROME 来引用它的路径
echo $J_CHROME
# 输出: /Applications/Google Chrome.app
```

详见「环境变量」。
