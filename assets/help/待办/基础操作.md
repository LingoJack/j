# 待办基础

j-cli 的待办功能帮你管理任务清单。最棒的是——完成任务后可以自动写入日报，不用重复记录。

## 怎么打开待办？

```bash
j todo          # 或 j td
```

这会打开一个全屏待办界面，就像一个清单 App：
- 左边是待办列表
- 可以用键盘添加、完成、删除待办

## 快速添加待办

如果只想快速添加一条，不用打开界面：

```bash
j todo add 买牛奶
j todo add 完成登录功能
j todo add 回复邮件
```

## 待办界面怎么操作？

打开待办界面后（`j todo`）：

| 按键 | 作用 |
|------|------|
| `↑` / `k` | 上移选中 |
| `↓` / `j` | 下移选中 |
| `空格` / `Enter` | 标记完成/取消完成 |
| `a` | 添加新待办 |
| `e` | 编辑选中的待办 |
| `d` | 删除选中的待办 |
| `f` | 切换过滤（全部/未完成/已完成） |
| `q` | 退出 |

## 完成待办时自动写日报

当你按 `空格` 标记一条待办为完成时，系统会问：

```
是否写入日报？[y/N]
```

- 按 `y` 或 `Enter`：写入日报，同时保存待办
- 按其他键：只标记完成，不写日报

这样你就不用在两个地方重复记录了。

## 查看待办列表

```bash
j todo list           # 显示所有待办
j todo list --done    # 只显示已完成的
j todo list --undone  # 只显示未完成的
```

## 待办存在哪里？

保存在 `~/.jdata/report/todo.json`。

即使退出界面，待办也会自动保存。下次打开时会恢复。

## 常见问题

**Q：待办排序能调整吗？**

A：可以。在界面里用 `J`（大写）下移，`K`（大写）上移，调整顺序。

**Q：不小心删了待办怎么办？**

A：删除前会确认。确认后无法恢复。

**Q：怎么批量添加待办？**

A：目前只能逐条添加。或者在界面里连续按 `a` 添加多条。
