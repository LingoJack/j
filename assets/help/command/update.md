## 更新

### 更新命令

```bash
j update               # 自动检测安装来源并更新到最新版本
j update --check       # 仅检查是否有新版本（不执行更新）
```

### 更新方式

`j update` 会自动识别当前的安装来源并选择对应的更新方式：

| 安装来源 | 更新方式 |
|----------|----------|
| 一键安装脚本 | 自动下载最新二进制文件替换 |
| cargo install | 执行 `cargo install j-cli` 重新编译安装 |

### 平台差异

| 平台 | 更新包格式 |
|------|-----------|
| macOS / Linux | `.tar.gz` 解压 |
| Windows | `.zip` 解压 |
