# 斜杠命令

在输入框中输入 `/` 即可唤起斜杠命令弹窗，支持模糊过滤：

| 命令 | 说明 |
|------|------|
| `/copy` | 复制最后一条 AI 回复 |
| `/log` | 打开日志窗口 |
| `/browse` | 浏览历史消息 |
| `/config` | 打开配置界面 |
| `/model` | 切换模型 |
| `/archive` | 归档当前对话 |
| `/clear` | 新建对话（清空当前会话） |
| `/theme` | 切换主题 |
| `/resume` | 恢复历史会话 |
| `/dump` | 导出原始 session messages |
| `/dump-processed` | 导出经完整处理管线后的最终数据 |
| `/teammate` | 打开 Teammate 面板 |
