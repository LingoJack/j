## 文件预览

通过 `j read <file>` 在浏览器中打开 Typora 风格的实时编辑器，支持 Markdown
所见即所得（WYSIWYG）渲染、文件树、标签页、目录大纲等。

### 基本用法

```bash
j read <file>           # 预览/编辑文件（默认后台启动 + 立即返回 prompt）
j read <dir>            # 以目录为根打开文件树
j read ~/notes/demo.md  # 支持 ~ 路径展开
j rd <file>             # 简写别名
```

### 默认是后台模式

`j read` 默认会在后台启动 server 并立刻返回，类似 `code .` / `typora foo.md`：

```
$ j read README.md
📖 reader 已启动：http://127.0.0.1:54321/
   关闭浏览器页面会自动停止后台 server（也可通过心跳超时自动退）
   (后台 PID = 12345)
$            ← 立刻回到 prompt，不卡 stdin
```

什么时候 server 会自动退出：

1. 你关掉那个浏览器窗口（`⌘W` 在 Chrome app 模式 / 关标签页 / 关整个浏览器）
2. 浏览器异常关闭、断网等导致心跳超时（默认 30 秒）
3. 显式 `kill <PID>`

### 参数说明

| 参数 | 说明 |
|------|------|
| `--port <N>` | 指定监听端口（默认随机分配空闲端口） |
| `--no-open` | 不自动打开浏览器，只输出访问 URL |
| `--tab` | 用普通浏览器标签页而不是 Chrome app 模式打开 |
| `--foreground` / `--fg` | 前台运行，便于查看 server 日志；按 `Ctrl+C` 停止 |

> Chrome app 模式（默认）的窗口没有标签栏、没有地址栏，⌘W / ⌘T
> 等快捷键会被网页接收，体验更接近原生应用。如果你的系统找不到
> Chrome / Edge / Chromium / Brave，会自动回退到普通标签页。

### 浏览器界面

```
┌──────────┬─────────────────────────────────────┬──────────┐
│  文件树  │    Tab 条 + 编辑器                  │  目录大纲 │
│          │   ┌───────────┐                     │          │
│  📁 docs │   │ README.md │ CHANGELOG.md ●     │  v1.0    │
│  📄 a.md │   └───────────┘                     │  v0.9    │
│  📄 b.md │   面包屑 / 路径 / 状态徽章 / 工具按钮│   ...    │
│          │   ─────────────────────────────────│          │
│          │   实时 WYSIWYG 编辑区               │          │
└──────────┴─────────────────────────────────────┴──────────┘
```

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `⌘ S` / `⌃ S` | 保存当前文件 |
| `⌘ W` / `⌃ W` | 关闭当前 Tab；当前没有 Tab 时退出 reader |
| `⌘ ⇧ ←` / `⌘ ⇧ →` | 切换前后 Tab（环形） |

> macOS 普通 Chrome 标签页里 `⌘W` 会被浏览器吞掉关 tab；这正是默认走
> Chrome **app 模式**的原因。如果你必须用 `--tab`，可以退而用 `⌃W`
> 关闭当前 Tab。

### 示例

```bash
# 最常见：在浏览器后台开一个文件，立刻回 prompt
j read report.md

# 调试 server，看日志
j read report.md --foreground

# 指定端口（适合多窗口共享同一个 reader）
j read . --port 9876

# 仅启动服务，自己用浏览器打开
j read doc.md --no-open

# 不喜欢 app 模式，用普通标签页
j read doc.md --tab
```

### 支持的文件格式

| 格式 | 渲染方式 |
|------|----------|
| `.md` / `.markdown` / `.mdx` | Milkdown WYSIWYG（标题、代码块、表格、列表、HTML 透传等） |
| 其他文本（`.txt` / `.log` / 代码文件等） | 纯文本编辑 |

### 限制

- 单文件大小上限：5 MiB
- 静态资源（图片等）大小上限：20 MiB
- 单次目录列出上限：2000 项（更多会提示「目录过大」）
- 仅监听 `127.0.0.1`，不暴露到局域网
- 仅支持本地文件路径
