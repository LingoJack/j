## 文件预览

`j read <path>` 会启动独立的 **jstudio reader** Tauri 桌面应用，用于预览/编辑本地文件或以目录为根打开文件树。

> reader 已从 `j-cli` 主二进制中拆出为独立 Tauri 应用。`j read` 现在只是 launcher：校验路径并启动已安装的 `jstudio` app，不再内置浏览器 server、端口或静态资源。

### 安装 reader app

首次使用前需要先安装 reader app。

#### macOS 推荐方式

在 `j-cli` 仓库根目录执行：

```bash
make reader-install
```

该命令会自动：

1. 初始化 reader submodule：

```bash
git submodule update --init --recursive apps/jstudio
```

2. 安装 reader 前端依赖：

```bash
cd apps/jstudio && npm install --silent
```

3. 构建 Tauri app：

```bash
cd apps/jstudio && npm run tauri:build
```

4. 安装到：

```text
/Applications/jstudio.app
```

安装完成后即可使用：

```bash
j read README.md
j read ~/notes
```

如果想安装到自定义目录：

```bash
make reader-install READER_INSTALL_APP_DIR="$HOME/Applications"
```

#### 非 macOS 平台

执行：

```bash
make reader-install
```

命令会构建 reader 二进制，并提示设置 `JSTUDIO_BIN`：

```bash
export JSTUDIO_BIN=/path/to/apps/jstudio/src-tauri/target/release/jstudio
j read <file_or_dir_path>
```

`j read` 会优先读取 `JSTUDIO_BIN` 环境变量。

### Reader Makefile 命令

| 命令 | 说明 |
|------|------|
| `make reader-init` | 初始化 `apps/jstudio` submodule 并安装前端依赖 |
| `make reader-dev` | 启动 reader Tauri 开发模式 |
| `make reader-build` | 构建 reader Tauri 应用 |
| `make reader-install` | 构建并安装 reader app |
| `make reader-uninstall` | 卸载 macOS 下的 `/Applications/jstudio.app` |
| `make reader-clean` | 清理 reader 构建产物 |

### 基本用法

```bash
j read <file>           # 打开文件
j read <dir>            # 以目录为根打开文件树
j read ~/notes/demo.md  # 支持 ~ 路径展开
j rd <file>             # 简写别名
```

### launcher 查找顺序

`j read` 会按顺序查找 reader app：

1. `JSTUDIO_BIN` 环境变量指定的可执行文件；
2. macOS 常见安装位置：
   - `/Applications/jstudio.app`
   - `/Applications/Jstudio.app`
   - `/Applications/JStudio.app`
3. 当前仓库开发构建产物：
   - `apps/jstudio/src-tauri/target/release/bundle/macos/jstudio.app`
   - `apps/jstudio/src-tauri/target/debug/bundle/macos/jstudio.app`
   - `apps/jstudio/src-tauri/target/release/jstudio`
   - `apps/jstudio/src-tauri/target/debug/jstudio`
4. 系统 `PATH` 中的：
   - `jstudio`
   - `Jstudio`
   - `JStudio`

如果没有找到，会提示先执行：

```bash
make reader-install
```

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `⌘ S` / `⌃ S` | 保存当前文件 |
| `⌘ W` / `⌃ W` | 关闭当前 Tab；当前没有 Tab 时退出 reader |
| `⌘ ⇧ ←` / `⌘ ⇧ →` | 切换前后 Tab（环形） |

### 示例

```bash
# 打开单个文件
j read report.md

# 以当前目录为根打开文件树
j read .

# 使用自定义 reader 二进制
JSTUDIO_BIN="$HOME/bin/jstudio" j read ~/notes
```

### 支持的文件格式

| 格式 | 渲染方式 |
|------|----------|
| `.md` / `.markdown` / `.mdx` | Milkdown WYSIWYG（标题、代码块、表格、列表、HTML 透传等） |
| 常见图片格式 | 图片预览 |
| 其他文本（`.txt` / `.log` / 代码文件等） | 纯文本编辑 |

### 限制

- 单文件大小上限：5 MiB
- 静态资源（图片等）大小上限：20 MiB
- 单次目录列出上限：2000 项（更多会提示「目录过大」）
- 仅支持本地文件路径
