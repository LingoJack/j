## 文件预览

通过 `j read <file>` 在浏览器中预览文件内容，支持 Markdown 渲染。

### 基本用法

```bash
j read <file>           # 预览文件（自动打开浏览器）
j read ~/notes/demo.md  # 支持 ~ 路径展开
j rd <file>             # 使用简写别名
```

### 参数说明

| 参数 | 说明 |
|------|------|
| `--port <PORT>` | 指定监听端口（默认随机分配空闲端口） |
| `--no-open` | 不自动打开浏览器，仅输出访问 URL |

### 示例

```bash
j read report.md                    # 预览当前目录下的 Markdown 文件
j read ~/.jdata/report/week.md      # 预览 home 目录下的文件
j read slides.md --port 8080        # 指定端口预览
j read doc.txt --no-open            # 仅输出 URL，不打开浏览器
```

### 支持的文件格式

| 格式 | 渲染方式 |
|------|----------|
| `.md` / `.markdown` | Markdown 渲染（标题、代码块、表格、列表等） |
| 其他格式 | 纯文本显示 |

### 限制

- 文件大小上限：5 MiB
- 仅支持本地文件路径
- 服务运行期间终端会阻塞，按 `Ctrl+C` 退出
