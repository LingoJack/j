## 系统配置

### 配置命令

| 命令 | 说明 |
|------|------|
| `j config <section> <field> <val>` | 直接修改配置字段 |
| `j clear` | 清屏 |
| `j version` / `j v` | 查看版本信息 |
| `j help` / `j h` | 打开多标签帮助 TUI |
| `j exit` / `j q` / `j quit` | 退出（交互模式，或按 `Ctrl+Q` / `Ctrl+D`） |

### 帮助界面快捷键

| 按键 | 功能 |
|------|------|
| `<-` / `->` / `h` / `l` | 切换帮助 Tab |
| `Tab` / `Shift+Tab` | 切换到下一个 / 上一个 Tab |
| `1`-`0` | 直接跳到指定 Tab |
| `上` / `下` / `j` / `k` | 滚动内容 |
| `PageUp` / `PageDown` | 快速滚动 |
| `Home` / `End` | 跳到顶部 / 底部 |
| `q` / `Esc` / `Ctrl+C` | 退出帮助 |
