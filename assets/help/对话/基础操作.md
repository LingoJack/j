# AI 对话基础

j-cli 内置了 AI 对话功能，你可以在终端里直接和 AI 交流，让它帮你写代码、回答问题、分析文件。

## 两种使用方式

### 方式一：对话界面（推荐）

```bash
j chat          # 或 j ai
```

这会打开一个全屏对话界面，就像微信聊天一样：
- 左边是聊天记录
- 底部是输入框
- 按 `Enter` 发送消息
- 按 `Esc` 退出

**适合场景**：多轮对话、需要上下文、复杂任务

### 方式二：快速提问

```bash
j ai "你的问题"
```

这会直接发送问题，AI 回复后打印出来，然后退出。

**适合场景**：单次提问、脚本调用、快速查询

**示例**：

```bash
j ai "Python 怎么读取 JSON 文件？"
j ai "帮我写一个冒泡排序"
j ai "这个正则表达式是什么意思：^[a-z]+$"
```

> 注意：如果问题包含 `|`、`>`、`<`、`&` 等 shell 特殊字符，要用引号包裹：
> `j ai "请解释 ls | grep rs 的含义"`

## 继续上一次对话

如果你之前在对话界面里聊过天，下次可以用 `-c` 继续：

```bash
j ai -c
```

这样会恢复上一次的聊天记录，不用重新说明背景。

## 对话界面怎么操作？

进入对话界面后（`j ai`）：

| 按键 | 作用 |
|------|------|
| `Enter` | 发送消息 |
| `Shift+Enter` | 换行（输入多行内容） |
| `↑` / `↓` | 滚动查看历史消息 |
| `/` | 打开命令菜单（复制、归档、切换主题等） |
| `Ctrl+E` | 打开配置界面（设置 API Key、切换模型） |
| `Esc` | 退出对话 |

## 第一次使用？

第一次运行 `j ai` 时，会自动进入配置界面，让你设置 API Key：

1. 选择一个 AI 提供商（比如 OpenAI、Anthropic）
2. 输入 API Key
3. 选择模型（比如 gpt-4o、claude-3-sonnet）

配置完成后就可以开始对话了。

## 常见问题

**Q：对话记录保存在哪里？**

A：保存在 `~/.jdata/agent/sessions/` 目录下。下次打开会自动恢复。

**Q：怎么切换 AI 模型？**

A：在对话界面按 `Ctrl+E`，进入 Model Tab，用 `Tab` 切换提供商，`s` 设置为当前使用。

**Q：怎么复制 AI 的回复？**

A：按 `Ctrl+Y` 复制最后一条回复，或者按 `/` 打开命令菜单选择 `/copy`。

**Q：怎么让 AI 读取文件？**

A：在输入框输入 `@file:` 然后选择文件路径，AI 就能看到文件内容。比如：`请分析 @file:src/main.rs 这个文件`
