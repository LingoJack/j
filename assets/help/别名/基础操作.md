# 别名基础操作

别名就是给应用、文件、网址起一个短名字。以后在终端输入这个名字就能打开对应的东西。

## 为什么需要别名？

想想你平时怎么打开 Chrome：
1. 用鼠标点 Dock 图标
2. 或者用 Spotlight 搜索 "Chrome"
3. 或者用 Alfred 等工具

用别名后：

```bash
j chrome    # 一步到位
```

更强大的是，别名之间可以组合使用：

```bash
j chrome github          # 用 Chrome 打开 GitHub
j vscode ./src           # 用 VSCode 打开 src 目录
j chrome "rust lang"     # 用 Chrome 搜索 "rust lang"
```

## 怎么设置别名？

```bash
j set <名字> <路径或网址>
```

**设置应用别名**：

```bash
j set chrome "/Applications/Google Chrome.app"
j set vscode "/Applications/Visual Studio Code.app"
j set music "/Applications/Spotify.app"
```

**设置网址别名**：

```bash
j set github https://github.com
j set google https://google.com
```

**设置文件/目录别名**：

```bash
j set project ~/my-project
j set notes ~/Documents/notes
```

> j-cli 会自动识别：`.app` 结尾的是应用，`http` 开头的是网址，其他是文件路径

## 管理别名

```bash
j ls              # 查看所有别名
j ls all          # 查看所有分类的别名
j ls path         # 只看文件/目录类的别名
j ls inner_url    # 只看网址类的别名

j rm chrome       # 删除 chrome 别名
j rename chrome gc  # 把 chrome 重命名为 gc
j mf chrome "/Applications/Chromium.app"  # 修改 chrome 指向的路径
```

## 打开方式

设置好别名后，有三种打开方式：

```bash
j chrome          # 直接打开 Chrome 应用
j chrome github   # 用 Chrome 打开 github 这个网址别名
j chrome "hello"  # 用 Chrome 搜索 "hello"（默认用 Bing，可配置）
```

要支持组合打开，需要先给浏览器打上 `browser` 标签：

```bash
j tag chrome browser     # 标记 chrome 为浏览器
j tag vscode editor      # 标记 vscode 为编辑器
```

标记后就可以这样用：

```bash
j chrome github          # 浏览器 + 网址 = 用 Chrome 打开 GitHub
j vscode ./src           # 编辑器 + 路径 = 用 VSCode 打开 src 目录
j chrome "rust lang"     # 浏览器 + 文字 = 用 Chrome 搜索
```

## 智能识别

j-cli 会根据目标类型自动选择打开方式：

| 目标类型 | 打开方式 | 示例 |
|----------|----------|------|
| `.app` 应用 | 系统打开 | `j chrome` 打开 Chrome |
| 可执行文件 | 终端执行 | `j python script.py` 执行脚本 |
| 网址 | 默认浏览器打开 | `j github` 打开 GitHub |
| 文件/目录 | 系统打开 | `j project` 打开项目文件夹 |

## 常见问题

**Q：别名保存在哪里？**

A：保存在 `~/.jdata/aliases/` 目录下。

**Q：能不能给同一个应用设置多个别名？**

A：可以。比如 `j set chrome "/Applications/Google Chrome.app"` 和 `j set gc "/Applications/Google Chrome.app"` 都可以。

**Q：别名支持 Tab 补全吗？**

A：支持。输入 `j chro` 然后按 `Tab`，会自动补全为 `j chrome`。
