# 什么是 j-cli？

j-cli 是一个命令行工具集，把常用的效率工具整合到一个命令里。就像手机上的「万能遥控器」，一个命令就能控制各种应用和工作流程。

## j-cli 能做什么？

| 功能 | 作用 | 举个例子 |
|------|------|----------|
| **别名管理** | 给应用、网址起个短名字，一键打开 | `j chrome` 打开浏览器，`j vscode` 打开编辑器 |
| **AI 对话** | 在终端里和 AI 聊天、写代码、分析文件 | `j ai` 进入对话界面，问问题、让它帮你干活 |
| **日报记录** | 快速写工作日报，不用打开编辑器 | `j report "完成登录功能"` 一行写入 |
| **待办备忘** | 管理任务清单，完成后自动记入日报 | `j todo` 打开待办界面，逐个完成打勾 |
| **笔记管理** | Markdown 笔记本，写文档、记笔记 | `j md` 打开笔记列表，选中编辑 |
| **脚本执行** | 保存常用命令脚本，一键运行 | `j script deploy` 执行部署脚本 |

## 怎么用？

所有命令都以 `j` 开头，后面跟功能名。就像这样：

```bash
# 打开应用（别名功能）
j chrome              # 打开 Chrome 浏览器
j vscode              # 打开 VSCode 编辑器

# 和 AI 聊天
j ai                  # 进入对话界面
j ai "帮我写一个排序函数"  # 直接提问，打印回复

# 写日报
j report "完成首页开发"   # 写入今日日报
j check               # 查看最近几条日报

# 管理待办
j todo                # 打开待办界面
j todo add 买牛奶      # 快速添加一条待办

# 写笔记
j md                  # 打开笔记列表
j md 项目文档          # 打开或新建笔记
```

## 核心概念：别名

别名是 j-cli 最基础的功能。给常用的应用、文件、网址起一个短名字，以后用这个名字就能打开。

**场景：每天都要打开 Chrome、VSCode、Terminal 三个应用**

- 传统方式：点 Dock 图标，或者 Spotlight 搜索，三步操作
- 用别名：`j chrome`、`j vscode`、`j term` 三条命令，两秒搞定

**怎么设置别名？**

```bash
# 设置 Chrome 的别名为 chrome
j set chrome "/Applications/Google Chrome.app"

# 设置 VSCode 的别名为 vscode  
j set vscode "/Applications/Visual Studio Code.app"

# 设置一个网址的别名
j set github https://github.com

# 现在可以这样用：
j chrome              # 打开 Chrome
j github              # 打开 GitHub（用默认浏览器）
j chrome github       # 用 Chrome 打开 GitHub
j vscode ./src        # 用 VSCode 打开 src 目录
```

## 核心概念：AI 对话

j-cli 内置了 AI 对话功能，可以直接在终端里和 AI 交互。不用打开浏览器、不用切换窗口。

**场景：写代码时需要查一个函数的用法**

- 传统方式：打开浏览器 → 搜索 → 找文档 → 切回编辑器
- 用 j-cli：`j ai "Python 怎么读取 JSON 文件"`，AI 直接回答，不离开终端

**怎么开始对话？**

```bash
j ai                  # 进入全屏对话界面（推荐）
j ai 你的问题          # 快速提问，打印回复后退出
```

进入对话界面后：
- 输入问题，按 `Enter` 发送
- AI 回复时，可以用 `Ctrl+C` 中断
- 按 `/` 可以看到所有快捷命令
- 按 `Esc` 退出对话

## 核心概念：日报

j-cli 把写日报这件事简化成一行命令。不用打开文件、不用找位置、不用写日期。

**场景：刚完成一个任务，想记下来**

- 传统方式：打开日报文件 → 找到今天的日期 → 写内容 → 保存关闭
- 用 j-cli：`j report "完成登录功能"`，一行搞定

**怎么写日报？**

```bash
j report "完成首页布局"      # 写入今日日报
j report "修复登录bug"       # 再写一条
j check                     # 查看最近 10 条
j check 20                  # 查看最近 20 条
```

## 核心概念：待办

待办功能帮你管理任务清单。完成后可以自动写入日报，不用重复记录。

**场景：今天有三个任务要完成**

```bash
j todo                    # 打开待办界面
# 按 a 添加三条待办：
# - 完成首页布局
# - 修复登录bug
# - 写单元测试

# 逐个完成后按空格打勾，系统会问是否写入日报
```
