# 笔记本基础

j-cli 内置了一个 Markdown 笔记本。可以在终端里写笔记、记文档，支持实时预览。

## 怎么打开笔记本？

```bash
j md          # 或 j nb、j notebook
```

这会打开一个全屏界面：
- 左边是笔记列表（支持目录分类）
- 右边是编辑/预览区

## 快速打开笔记

如果你知道笔记名字，可以直接打开：

```bash
j md 项目文档          # 打开或新建"项目文档"笔记
j md ~/Desktop/a.md   # 编辑任意 Markdown 文件
```

## 笔记界面怎么操作？

打开界面后（`j md`）：

| 按键 | 作用 |
|------|------|
| `↑` / `k` | 上移选中 |
| `↓` / `j` | 下移选中 |
| `Enter` / `e` | 打开编辑选中的笔记 |
| `a` | 新建笔记 |
| `d` | 删除笔记 |
| `r` | 重命名笔记 |
| `p` | 全屏预览 |
| `Tab` | 展开/折叠目录 |
| `q` | 退出 |

## 笔记存在哪里？

保存在 `~/.jdata/notebook/` 目录下，每个笔记是一个 `.md` 文件。

你可以用子目录分类：

```bash
j md mkdir 工作         # 创建"工作"目录
j md mv 项目文档 工作    # 把"项目文档"移到"工作"目录下
```

## 其他命令

```bash
j md list              # 列出所有笔记
j md search 关键字      # 搜索笔记（标题和内容）
j md open              # 在 Finder 中打开笔记目录
j md rename 旧名 新名   # 重命名笔记
j md delete 笔记名      # 删除笔记
```

## 常见问题

**Q：支持哪些格式？**

A：支持 Markdown 格式（.md 文件）。编辑时可以实时预览渲染效果。

**Q：能编辑笔记本外面的文件吗？**

A：可以。`j md ~/Desktop/a.md` 可以编辑任意路径的 Markdown 或文本文件。

**Q：笔记数据会丢失吗？**

A：笔记就是普通的 .md 文件，保存在 `~/.jdata/notebook/` 下。退出时自动保存。
