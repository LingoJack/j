# 日报基础

j-cli 把写日报这件事简化成一行命令。不用打开文件、不用找位置、不用写日期——全部自动处理。

## 怎么写日报？

一行命令搞定：

```bash
j report "完成登录功能开发"
```

这会自动在日报文件里追加一行：`[2026-02-25] 完成登录功能开发`

你随时可以继续写：

```bash
j report "修复支付模块 bug"
j report "代码评审通过"
```

## 查看日报

```bash
j check           # 查看最近 10 条
j check 20        # 查看最近 20 条
j check open      # 用内置编辑器打开全文编辑
```

## 用编辑器写日报

如果你想写一大段内容，可以用：

```bash
j report
```

这会打开内置编辑器，显示最近几条日报作为上下文，方便你接着写。写完后按 `Esc` 保存退出。

## 搜索日报

```bash
j search 10 登录        # 最近 10 条中搜索 "登录"
j search all 支付       # 全部日报中搜索 "支付"
j search 20 bug -f      # 模糊搜索 "bug"（不区分大小写）
```

## 日报存在哪里？

默认保存在 `~/.jdata/report/week_report.md`。

日报按周分组，每周一个标题。格式如下：

```markdown
# Week 8

[2026-02-24] 完成首页布局
[2026-02-24] 修复导航栏样式
[2026-02-25] 完成登录功能开发
[2026-02-25] 修复支付模块 bug
```

## 常见问题

**Q：日报格式是什么样的？**

A：每条记录格式为 `[日期] 内容`，日期自动生成，按周分组。

**Q：怎么开始新的一周？**

A：`j reportctl new` 会创建新的一周标题。

**Q：能不能和团队共享日报？**

A：可以。通过 git 同步：`j reportctl push` 推送，`j reportctl pull` 拉取。详见「管理命令」。

**Q：怎么改日报文件路径？**

A：`j config report week_report <路径>` 自定义保存位置。详见「路径配置」。
