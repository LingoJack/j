# 合并日报

把另一个仓库或本地路径的日报 **增量合并** 到当前日报文件中。适合多设备 / 多人汇总日报的场景。

## 基本用法

```bash
j reportctl merge <url|path>
```

`<url|path>` 可以是：

| 类型 | 示例 | 说明 |
|------|------|------|
| 远程 git URL | `https://github.com/user/repo.git` | 自动 clone（浅克隆 main 分支，失败回退 master），读取后清理临时目录 |
| 本地目录 | `~/my-report` | 在目录下查找同名日报文件，找不到则回退 `week_report.md` |
| 本地文件 | `~/my-report/week_report.md` | 直接读取该文件 |

## 合并远程仓库

```bash
# 合并 GitHub 上的日报仓库
j reportctl merge https://github.com/user/report.git
```

执行流程：
1. 浅克隆远程仓库到临时目录
2. 读取其中的日报文件（优先同名，回退 `week_report.md`）
3. 与本地日报增量合并后写回
4. 自动清理临时目录

## 合并本地路径

```bash
# 合并另一个目录下的日报
j reportctl merge ~/work/report-backup

# 直接指定日报文件
j reportctl merge ~/Desktop/week_report.md
```

## 增量去重规则

合并采用 **增量去重** 策略，只把源日报中目标日报还没有的条目合并进来：

- **日期范围相同的周**：逐条比较，只追加目标周中不存在的条目；已存在的条目自动跳过
- **日期范围不同的周**：作为新周整体插入，最终按起始日期排序并重新编号
- **所有条目均已存在**：不写入任何文件，直接提示「无需合并」

> 去重比较按条目内容（忽略首尾空白和空行差异），而非按日期判断。即使两条目日期相同但内容不同，也会各自保留。

### 示例

本地日报：

```markdown
# Week1[2026.02.23-2026.03.01]

- 【2026/02/23】 完成登录功能
- 【2026/02/24】 修复导航栏 bug
```

源日报：

```markdown
# Week3[2026.02.23-2026.03.01]

- 【2026/02/23】 完成登录功能
- 【2026/02/25】 代码评审
```

合并后：

```markdown
# Week1[2026.02.23-2026.03.01]

- 【2026/02/23】 完成登录功能
- 【2026/02/24】 修复导航栏 bug
- 【2026/02/25】 代码评审
```

> 源日报中的 `【2026/02/23】 完成登录功能` 已存在，被跳过；只有 `【2026/02/25】 代码评审` 被追加。周编号以本地为准重新编号。

## 多行条目处理

如果一条日报包含多行内容（子列表、补充说明等），合并时会以 **条目块** 为单位整体比较和迁移，不会拆散：

```markdown
- 【2026/02/25】 完成接口开发
  - 用户接口
  - 订单接口
  这里是补充说明
```

以上整块会作为一个整体参与去重比较和追加，不会被截断。

## 备份机制

合并前会自动备份原日报文件：

- 备份文件名：在原文件名后加 `.bak`（如 `week_report.md` -> `week_report.md.bak`）
- 备份成功后才写入合并结果
- 如果备份失败，合并会中止，原文件不受影响
- 如果源日报所有条目均已存在（无需合并），则不会触发备份

## 常见问题

**Q：合并后周编号变了？**

A：正常。合并后所有周会按起始日期重新排序并编号（Week1, Week2, ...），编号可能与原来不同。

**Q：重复执行 merge 会产生重复条目吗？**

A：不会。合并是增量去重的，已存在的条目会自动跳过。可以放心多次执行。

**Q：两条目日期相同但内容不同，会被去重吗？**

A：不会。去重按条目的完整内容比较（忽略空白差异），而非仅按日期。日期相同但内容不同的条目会各自保留。

**Q：远程仓库需要什么格式？**

A：仓库中需要包含日报文件（默认 `week_report.md`，或与本地配置同名的文件）。会优先 clone `main` 分支，失败则尝试 `master`。

**Q：合并远程仓库很慢？**

A：使用的是浅克隆（`--depth 1`），只拉取最新一次提交，通常很快。如果网络不佳请耐心等待或使用本地路径合并。
