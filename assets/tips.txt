# shell
- 单独输入 `!` 或 `！` 进入 shell mode，输入 `exit` 或按 Ctrl+D 返回 jcli。
- 输入 `! <command>` 可临时执行 shell 命令，例如 `! ls`。
- `! <command>` 会加载 zsh/bash rc，`ll` 这类 alias 也可以使用。
- shell mode 的 prompt 会显示当前目录、Git 分支和未提交变更标记 `✱`。
- shell mode 中可直接使用系统命令，适合连续执行多条 shell 操作。

# prompt
- 普通交互模式 prompt 中的 `(jcli)` 表示当前在 jcli REPL。
- prompt 中的 ` <branch>` 表示当前 Git 分支。
- prompt 中出现黄色 `✱` 表示当前 Git 工作区存在未提交、未暂存或未跟踪变更。
- 命令执行结束后 prompt 前会空一行，方便区分上一条命令输出。

# completion
- Tab 键可补全 jcli 命令、别名和文件路径。
- 输入 `!` 后按 Tab 可补全文件路径，适合快速执行 shell 命令。
- 命令参数位置支持智能补全，例如分类、配置分区、配置字段和值。

# help
- `help` 查看所有可用命令与用法。
- `help <topic>` 查看指定主题帮助，例如 `help 对话`、`help 别名`。

# chat
- `chat` 或 `ai` 进入 AI 对话 TUI。
- `chat -c` 继续上一次对话。
- `chat --session <name>` 指定会话名。
- `ai "问题"` 可快速进行单次提问，例如 `ai "Python 怎么读取 JSON"`。
- `@file:<path>` 可让 AI 读取文件作为上下文，例如 `@file:src/main.rs 请分析`。
- Chat TUI 中按 `/` 打开斜杠命令菜单，可使用 `/copy`、`/model`、`/theme` 等命令。
- Chat TUI 中按 Ctrl+Y 复制最后一条 AI 回复，按 Ctrl+E 打开配置界面。
- Chat TUI 中按 Ctrl+B 浏览历史消息，按 Ctrl+G 打开日志窗口。
- Chat TUI 中可用 `/archive` 归档当前对话，`/clear` 新建对话。
- Chat TUI 中可用 `/resume` 恢复历史会话，`/dump` 导出原始消息。

# alias
- `set <alias> <path>` 可设置别名，应用、URL、文件和脚本均可。
- `set browser:<alias> <path>` 可直接设置分类别名，例如 `set browser:chrome "/Applications/Google Chrome.app"`。
- `set outer_url:<alias> <url>` 可设置外网地址别名，打开时会自动连接 VPN。
- `rm <alias>` 删除别名，`rename <old> <new>` 重命名别名。
- `list` 查看所有别名，`list all/browser/editor` 查看指定分类。
- `tag <alias> browser` 可把别名标记为浏览器，`tag <alias> editor` 可标记为编辑器。
- `j chrome github` 可用浏览器别名打开网址别名。
- `j vscode ./src` 可用编辑器别名打开目录。
- `j chrome "搜索内容"` 可用浏览器别名直接搜索。

# report
- `report "内容"` 可快速写入日报。
- `report` 会打开 TUI 编辑器，用于编写长内容日报。
- `check` 查看最近日报，`check open` 用编辑器打开日报全文。
- `search 10 关键词` 搜索最近 10 条日报。
- `search all 关键词 -f` 可模糊匹配搜索全部日报。
- `reportctl new` 开始新一周，`reportctl push/pull` 同步到远端。

# todo
- `todo` 或 `td` 进入待办管理 TUI。
- `todo add <content>` 可快速添加待办事项。
- `todo done 1 --report` 完成待办并写入日报。
- 待办界面按空格完成事项时，可选择是否写入日报。
- `todo list` 查看所有待办，`todo list --undone` 只看未完成事项。

# notebook
- `md` 或 `notebook` 打开笔记本 TUI。
- `md <file>` 打开或新建笔记。
- `md list` 列出所有笔记，`md search <keyword>` 搜索笔记。
- `md mkdir <dir>` 创建分类目录，`md mv <note> <dir>` 移动笔记。

# script
- `script <name>` 会打开 TUI 编辑器保存脚本。
- `script <name> <content>` 可直接保存脚本内容。
- 脚本中可用 `$J_<ALIAS>` 引用别名路径，例如 `echo $J_CHROME`。
- `<script-name> -w` 可在新终端窗口执行脚本。

# time
- `time countdown 25m` 启动倒计时，支持 `s`、`m`、`h` 单位。

# config
- `config <section> <key> <value>` 修改配置。
- `log mode verbose` 开启详细日志，`log mode concise` 恢复简洁日志。
- `update --check` 检查新版本。

# shortcut
- Ctrl+Q 可中断当前输入。
- Ctrl+D 可退出 jcli。
