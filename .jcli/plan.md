# Plan: 重构代码块渲染逻辑

## 需求

用户反馈：
1. 单独的 ``` 不应该渲染成围栏
2. 只有当有成对的 ``` 时才渲染成围框
3. 移除 ``` 自动补全功能

## 当前问题

现在的实现：
- 遇到任何 ``` 都会尝试渲染围栏
- 自动补全可能在用户不需要时触发
- 未闭合的代码块渲染不完整

## 新方案

### 渲染逻辑

1. **单个 ``` (不成对)**：显示为普通文本，不渲染围框
2. **成对的 ```**：渲染为完整的围框
   - 开始围栏：`┌─ lang ──────┐`
   - 内容行：`│ code        │`
   - 结束围栏：`└─────────────┘`

### 实现步骤

#### Step 1: 移除自动补全

修改 `handle_insert_mode` 函数，移除 ``` 回车自动补全逻辑。

#### Step 2: 添加代码块配对检测

添加方法检测当前 ``` 是否有配对的结束围栏：
```rust
fn has_matching_fence(fence_line: usize, lines: &[String]) -> bool
```

#### Step 3: 修改渲染逻辑

修改 `render_line` 和相关方法：
- 检测 ``` 行时，先检查是否有配对
- 有配对：渲染围框
- 无配对：渲染为普通文本

#### Step 4: 简化围栏行渲染

围栏行只在代码块完整时才显示边框样式。

### 预期效果

**未闭合的 ```**：
```
```rust
fn main() {}
```
（显示为原始文本，无特殊渲染）

**闭合的代码块**：
```
┌─ rust ─────────┐
│ fn main() {}   │
└────────────────┘
```
