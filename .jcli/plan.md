# 修复 GUI 搜索结果列表显示问题

## 问题分析

经过代码探索，发现以下问题：

### 根本原因
在 `gui/src-ui/src/App.tsx` 中，虽然代码获取了搜索结果并存入 `results` 状态，但 **没有在 JSX 中渲染搜索结果列表**。

当前 App.tsx 只渲染了搜索输入框。

### 窗口配置
- `tauri.conf.json` 中窗口高度固定为 `56px`
- 需要增加高度以容纳搜索结果

## 解决方案（固定大窗口 + 滚动展示）

### 1. 增大窗口尺寸
修改 `tauri.conf.json`：
- 宽度保持 560px
- 高度改为 ~400px（可容纳约 7-8 个结果项）
- 输入框固定在顶部
- 结果列表可滚动

### 2. 布局结构调整
```
┌─────────────────────────────────┐
│  j  输入命令或搜索...           │ ← 固定高度输入框
├─────────────────────────────────┤
│  结果项 1                       │
│  结果项 2                       │
│  结果项 3                       │ ← 可滚动区域
│  ...                            │
│                                 │
└─────────────────────────────────┘
```

### 3. 添加搜索结果列表
在 `App.tsx` 中添加结果列表渲染，支持滚动。

### 4. 添加样式
- 输入区域固定高度 56px
- 结果列表占据剩余空间
- 超出时显示滚动条（自定义样式）

## 实施步骤

1. **修改 `tauri.conf.json`**：增加窗口高度到 400px
2. **修改 `App.tsx`**：添加搜索结果列表渲染
3. **修改 `globals.css`**：添加布局和结果列表样式（含滚动样式）

## 文件变更清单

| 文件 | 变更内容 |
|------|----------|
| `gui/src-tauri/tauri.conf.json` | 窗口高度改为 400px |
| `gui/src-ui/src/App.tsx` | 添加结果列表渲染 |
| `gui/src-ui/src/styles/globals.css` | 布局样式 + 结果列表样式 + 滚动条样式 |
