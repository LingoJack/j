# 输入区 UI 改进方案

## 目标效果

### 正常状态
```
┌──────────────────────────────────────────────────────────────────┐
│ > 这是用户输入的内容...█                                          │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

### 空输入时（占位符）
```
┌──────────────────────────────────────────────────────────────────┐
│ > 输入消息，按 Enter 发送...                                      │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

### Loading 状态
```
┌──────────────────────────────────────────────────────────────────┐
│ ~> 这是用户输入的内容...                                          │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

## 改动点

### 修改 `src/command/chat/ui/chat.rs` 的 `draw_input` 函数

#### 1. 提示符逻辑
- 正常状态：`>` 使用 `input_prompt` 颜色
- Loading 状态：`~>` 使用 `input_prompt_loading` 颜色

#### 2. 占位符逻辑
- 当 `input.is_empty()` 时，显示占位符文字
- 占位符文字：`"输入消息，按 Enter 发送..."`
- 占位符样式：使用 `text_dim` 颜色

#### 3. 光标位置调整
- 提示符占用 2 字符宽度（`> `）
- 光标位置计算需要加上提示符偏移

### 视觉效果

| 状态 | 提示符 | 颜色 |
|------|--------|------|
| 正常 | `>` | `input_prompt` (主题绿色) |
| Loading | `~>` | `input_prompt_loading` (主题橙色) |

| 输入内容 | 显示 |
|----------|------|
| 空 | `> 输入消息，按 Enter 发送...` (占位符灰色) |
| 有内容 | `> 用户输入内容█` (光标高亮) |

## 改动文件清单

- `src/command/chat/ui/chat.rs` - 修改 `draw_input` 函数
