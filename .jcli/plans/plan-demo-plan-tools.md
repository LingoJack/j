# 五大工具演示总结计划

## 概述
本文档是五大协作工具（TODO / TASK / Agent / AgentTeam / Plan）的完整演示记录。

---

## 工具 1: TodoWrite / TodoRead

| 特性 | 说明 |
|------|------|
| 用途 | 会话内的轻量待办事项管理 |
| 持久性 | 仅在当前会话内有效 |
| 状态 | pending / in_progress / completed / cancelled |
| 关键规则 | 同一时间只能有 1 个 in_progress 项 |
| 操作 | 写入(TodoWrite)、读取(TodoRead)、合并更新(merge=true) |

## 工具 2: Task

| 特性 | 说明 |
|------|------|
| 用途 | 持久化的任务管理，支持依赖关系 |
| 持久性 | 跨会话持久 |
| 状态 | pending -> in_progress -> completed |
| 依赖 | 支持 blockedBy 设置任务间依赖 |
| 操作 | create / list / get / update |
| 特色 | 任务完成时自动解除下游阻塞 |

## 工具 3: Agent

| 特性 | 说明 |
|------|------|
| 用途 | 启动子代理自主执行复杂多步任务 |
| 模式 | foreground(同步等待) / background(异步后台) |
| 隔离 | 子代理使用全新上下文，防止递归 |
| 能力 | 可使用除 Agent 外的所有工具 |
| 适用 | 复杂的多步骤研究或编码任务 |

## 工具 4: AgentTeam

| 特性 | 说明 |
|------|------|
| 用途 | 创建多个代理并行协作 |
| 通信 | 成员间通过 SendMessage 广播 |
| 模式 | 每个成员独立运行，真正并行 |
| 适用 | 全栈开发、多领域研究、需要并行工作的场景 |
| 创建 | 通过 AgentTeam 一次性创建多个 teammate |

## 工具 5: PlanMode

| 特性 | 说明 |
|------|------|
| 用途 | 编码前的只读探索和方案设计 |
| 模式 | 进入后只有只读工具可用 |
| 流程 | EnterPlanMode -> 探索/设计 -> 写计划 -> ExitPlanMode -> 用户审批 |
| 产物 | .jcli/plans/ 目录下的 Markdown 计划文件 |
| 适用 | 新功能实现、架构决策、多文件修改等非平凡任务 |

---

## 工具对比矩阵

| 维度 | TODO | Task | Agent | AgentTeam | Plan |
|------|------|------|-------|-----------|------|
| 复杂度 | 低 | 中 | 高 | 最高 | 中 |
| 持久性 | 会话级 | 跨会话 | 临时 | 临时 | 文件级 |
| 并行性 | 无 | 无 | 可选 | 是 | 无 |
| 决策权 | 主Agent | 主Agent | 子Agent | 多Agent | 用户 |

---

## 实施步骤

1. 本演示计划文件已完成撰写
2. 退出 Plan 模式提交给用户审批
3. 标记所有 TODO 项为完成状态

## 注意事项

- Plan 模式下无法执行任何写操作（文件编辑、Shell 命令等）
- 退出 Plan 模式后需要用户明确批准才能恢复写权限
- 计划文件会持久保存在 `.jcli/plans/` 目录中
