# HTML PPT 可视化编辑器方案

## 需求

用户希望有一个**像真正的 PowerPoint 那样的可视化编辑体验**来修改 HTML 幻灯片（`presentation/ppt/index.html`），而不是直接编辑 HTML 源码。内容仍然存储为 HTML，但编辑方式是可视化、所见即所得的。

## 现状

- PPT 是基于 `html-ppt-skill` 生成的 HTML 文件（`index.html` + `style.css`）
- `runtime.js` 已有丰富的演示功能：键盘导航、演讲者视图、Overview 网格、主题切换
- 编辑方式完全靠改源码，体验不直观

## 方案：为 runtime.js 新增 Edit Mode（E 键触发）

在现有的 `runtime.js` 中新增一个**可视化编辑模式**，通过按 `E` 键激活。编辑模式直接嵌入在浏览器中，无需额外服务。

### 核心功能

#### 1. 内容直接编辑（contenteditable）
- 进入编辑模式后，当前幻灯片的文本元素变为可编辑
- 点击任何文字即可直接修改（使用 `contenteditable`）
- 修改实时反映到 DOM

#### 2. 幻灯片管理侧栏
- 左侧显示幻灯片缩略图列表（复用现有的 Overview 缩略图逻辑）
- 支持点击切换当前编辑的幻灯片
- 显示幻灯片标题（来自 `data-title`）

#### 3. 属性面板
- 右侧属性面板，显示选中元素的样式信息
- 支持快速调整字体大小、颜色、加粗、对齐
- 支持修改 `data-title`（幻灯片标题）

#### 4. 保存到 HTML
- 编辑完成后，点击保存按钮
- JS 在浏览器中序列化 DOM 回完整 HTML 字符串
- 通过**下载文件**的方式保存（`Blob` + `URL.createObjectURL` + `<a download>`）
- 用户手动替换原文件即可

#### 5. 视觉反馈
- 编辑模式下显示蓝色编辑边框
- 被选中的元素高亮
- 幻灯片列表中当前编辑的页高亮
- 顶部工具栏显示编辑状态

### 技术实现

#### 新增文件
- `.jcli/skills/html-ppt-skill/assets/editor.js` — 编辑器核心逻辑（独立 JS 文件）

#### 修改文件
- `.jcli/skills/html-ppt-skill/assets/base.css` — 新增编辑模式相关样式（编辑态边框、侧栏、工具栏）
- `.jcli/skills/html-ppt-skill/assets/runtime.js` — 注册 `E` 键快捷键，加载编辑器

#### 编辑器架构

```
┌─────────────────────────────────────────────────────────┐
│ 编辑器工具栏  [保存] [撤销] [重做] | 幻灯片标题: xxx     │
├────────┬──────────────────────────────────┬──────────────┤
│ 幻灯片 │                                  │  属性面板    │
│ 缩略图  │     当前幻灯片 (可编辑)           │  字体大小    │
│ 列表    │                                  │  颜色        │
│        │                                  │  加粗/斜体   │
│ [1]    │    点击文字即可编辑               │  对齐方式    │
│ [2] ◀──│                                  │              │
│ [3]    │                                  │  data-title  │
│ ...    │                                  │              │
├────────┴──────────────────────────────────┴──────────────┤
│ 按 E 退出编辑模式 | Ctrl+S 保存 | Ctrl+Z 撤销            │
└─────────────────────────────────────────────────────────┘
```

#### 关键实现细节

1. **contenteditable 作用域**：只对文本节点（p, h1-h6, li, span, td, th, figcaption 等）启用 contenteditable，不对 SVG/代码块/img 等启用

2. **保存机制**：
   - 遍历 `.deck` 的所有子节点序列化为 HTML
   - 保留原始的 `<head>` 部分（CSS 引用等）
   - 清理编辑器注入的属性（`contenteditable`, 编辑器 class 等）
   - 生成完整 HTML 文件供下载

3. **撤销/重做**：维护一个 mutation 记录栈，记录每次内容变更

4. **与现有功能共存**：编辑模式下禁用翻页动画、演讲者模式等；退出编辑模式恢复所有正常功能

### 工作量估计

- `editor.js`：约 500-700 行（编辑器核心）
- `base.css` 新增：约 150 行（编辑模式样式）
- `runtime.js` 修改：约 10 行（E 键注册 + 加载 editor.js）

总计约 700-900 行代码。
